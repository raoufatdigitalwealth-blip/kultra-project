KULTRA SHOPIFY THEME
Install: Shopify admin > Online Store > Themes > Add theme > Upload zip file > choose kultra-shopify-theme.zip. Preview it, then Publish.
Then create these pages (Online Store > Pages) and set the Theme template:
  FAQ (handle: faq)  template: page.faq
  Contact (handle: contact)  template: page.contact
  Ingredient Checker (handle: ingredient-checker)  template: page.ingredient-checker
  About Us (handle: our-story)  template: page.about
  Find Your Protein (handle: find-your-protein)  template: page (default)
Blog: keep your existing blog with handle "journal" (Kultra Journal). Articles render in the Journal grid automatically.
Product: handle goat-whey-protein. Add to cart uses the pouch variant 46156107743255; the sample button uses variant 46156107776023. Subscriptions need a Shopify subscription app (selling plans) on the product.
